# Avellaneda–Stoikov Market Making Model

This repository contains explorations of the Avellaneda–Stoikov market-making model.

It consists of an implementation of the market-making model via market simulations as well as detailed notes on the original research paper, paying particular attention to the mathematical derivations, calculations and intuition behind the model.

## Reference

Avellaneda, M., & Stoikov, S. (2008). *High-frequency trading in a limit order book*. Quantitative Finance, 8(3), 217–224.

https://doi.org/10.1080/14697680701381228
